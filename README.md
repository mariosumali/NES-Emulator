# NES Emulator Web
NES emulator via the browser.

## Features
- Save & Load States
- Cheat System (Raw Address/Value)
- Frame-by-Frame Stepping
- Adjustable Screen Size (1x - 3x)
- Fully Remappable Controls
- Multiple Color Themes

## Usage
1. `npm install`
2. `npm run dev`
3. Load a `.nes` ROM and play.
